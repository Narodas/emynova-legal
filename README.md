# emynova – Rechtliches

Öffentlich gehostete Kopie der Datenschutzerklärung und Nutzungsbedingungen der App **emynova**, benötigt als öffentliche URL für App Store Connect / Google Play Console.

Enthält **ausschließlich** diese Rechtstexte — kein App-Quellcode, keine API-Keys, keine sonstigen Projektinterna.

Quelle der Texte: `src/content/legal/datenschutz.ts` und `src/content/legal/agb.ts` im (privaten) Haupt-Repo `emynova`. Bei Textänderungen dort muss `index.html` hier manuell nachgezogen werden — kein automatischer Sync.

Gehostet über GitHub Pages (Branch `main`, Root-Ordner).
